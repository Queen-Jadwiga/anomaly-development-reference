# Research investigations

> ADR document set: **v0.1.42**. Research revisions and source/build versions below describe their original scope.

One canonical dated record per question, named `YYYY-MM-DD-ID-topic.md`. Use the [investigation template](../templates/investigation.md), [workflow](../workflow.md) and [evidence policy](../evidence-policy.md).

Record question/scope, baselines, evidence/method, findings, missing edges, checks and disposition. API contracts belong in the [central API catalogs](../../02-lua-api/api-index.md); subsystem entry pages link investigations rather than copying their conclusions.

Earlier records retain their original format and IDs. Recent A-Life/Warfare records have moved here with forwarding pages at their former paths. Use [INDEX.md](../../INDEX.md) for the full research listing and [ROADMAP.md](../../ROADMAP.md) for current work.
